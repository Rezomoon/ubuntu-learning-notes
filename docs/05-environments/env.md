# Custome Enviroment Variables
ما برای یک سری از کار هامون یک سری اطلاعات مهم برای دسترسی به کارهامون نیاز داریم به کاستوم کردن 
Env Variables
و چون این اطاعات مهم هستند این اطلاعات رو در کد قرار نمیدهیم 

یعنی یک مقداری هستش که مورد استفاده و تغییر زیادی هستش 
مثلا :

- DataBase Configs
- Token

# اطلاعات ذخیره شده در سیستم

با این دستور به اطلاعات اینو ذخیره شده در سیستم دسترسی پیدا میکنیم 
```bash

    printenv
# or
    printenv | less

```
# نام گذاری

استاندارد نام گذاری باید با حروف بزرگ و با آندرلاین باشند مثل

```bash
DB_NAME = DataBase

```

# فراخوانی 
برای دسترسی به محتوای یک متغییر باید از دالار ساین استفاده کنیم

```bash

echo $USERNAME

```

# ساخت و ایحاد یک متفییر موقت
یک نکته 

<br>
اگر ترمینال خودتون رو ببندید دیگه به این متفییر ایجاد شده دستسرسی ندارید 


```bash

    export DB_NAME =myDB

```


# حذف یک متفییر

```bash
    unset DB_NAME
```


# ساخت و ذخیره یک متغییر
باید در فایل
- ./bashrc
که در دایرکتوری 
home
ما قرار دارد ذخیره کنیم

```bash
    cd ~
    vim bashrc

```

و در انتهای فایل باز شده این دستورات رو میزاریم

```bash

    export DB_NAME=dbName

```
و سپس  باید به سیستم بفهمانیم که چه تغییراتی ایجاد شده است

```bash
    source .bashrc
```
و حالا شما میتونید ببینیدش 
```bash
printenv | grep DB_
```


# ایجاد متغییر هایی برای تمامی کاربران 
برای این کار باید متغییر خودمون رو در فایل زیر ذخیره کنیم

```bash
    cd /
    sudo vim /etc/environment

```
و در اون فایل میتونیم متغییر خودمون رو اضافه کنیم
```bash
    DB_PASS=passpass
```
و برای دسترسی به متغییرمون یا باید ریبوت کنیم سیستممون رو یا باید لاگ اون و لاگین انجام بدیم




## /etc/enviroment

یک فایل هست که یک متغییر اینوایرمنت به اسم 
PATH

 اما این فایل داره چیکار میکنه دقیقا؟؟
 در واقع این لیستی از دایرکتوری فایل هارو داره که ما وفتی یک کامند لاین یا همون دستور رو توی ترمینال میدهیم شل دنبال کامند ما توی این دایرکتوری هایی که دستورات داخلشون ذخیره هست میگرده !
 اگر مسیر یک دستور اینجا مشخص نشده باشه اون دستور قابل اجرا نیستش !
