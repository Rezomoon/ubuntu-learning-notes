اما این مسیر توسیه نمیشه چون که ما قراره در کامند لاین  و با دستورات لینوکس کار کنیم !
پس لینوکس تکنولوژی های زیادی در اختیار ما قرار گذاشته !مثلا
apt , snap
این ها دو تا از مسیر های مختلف نصب برنامه ها هستند
البته با یکسری تفاوت اول بریم یک نگاه بهشون بندازیم
## snap ##  
برای درکش بهتره که به 
AppStore , PlayStore
تشبه ش کنم!
یعنی با این دستور شما دسترسی پیدا میکنید به یک سری از برنامه هایی که مورد تایید و قابل اعتماد هستند
یکی دیگه از ویژگی های اسنپ این هستش که حجم فایل هاش به علت اینکه تمامی برنامه ها در یک پکیج هستند و نصبش طولانی تر هست و زمان بوتش کند تر میشه و به خاطر این هستش که ایزوله هستش و اینجاست که شما ممکنه یک کتابخانه یا 
dependency
که برای چند برنامه مورد نیاز هستش رو با اسنپ چندین بار دانلودش کنید !

# مسیر لیست ها و آدرس ها 
در مسیر روت قرار بگیرید و کد های زیر را اجرا کنید
``` bash
ls /etc/apt
``` 
ls : لیست فایل های مسیر مورد نظر رو میده !
<br>
etc/apt : آدرسی و یک روت 

``` bash 
cat /etc/apt/sources.list.d/ubuntu.sources

```
cat : با این محتویات مسیر و فایلی که ازش میخواییم رو نشون میده !
<br>

<h4>

**search app**

</h4>

برای اینکه سرچ کنیم و ببینیم که آیا اپ مورد نظر ما جزو ریپو ها و مسیر های ای پی تی هست کامند زیر را اجرا میکنیم !!
```bash 
 - apt search appName
 ```
 apt : یک دستور و کامند لاین هستش برای مدیریت و دسترسی به برنامه های نصب شده روی سیستم

 search : جستجو کردن :D

 appName : اسم اپ مورد نظر

 نتیجه این کامند لیستی از ورژن های مختلف با نام های مختلف هستش ! که با برداشتن نام یکی از آن ها میتونیم با کامند زیر نصبش کنیم

## ** نصب یک برنامه با ای پی تی **

```bash
- apt install appNameBySearch
```
    - install = نصب کردن برنامه

**remove app **
برای پاک کردن یک برنامه با دستور زیر کار میکنیم
```bash
- apt remove appName
```
