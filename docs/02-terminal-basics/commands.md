# Redirect 

نتیجه یک کامند را در یک فایل ذخیره میکنه


#
محتویات اون فایل رو پاک میکنه و دوباره مینویستش
Over Write !
- >

```bash

    cd /home/admin

    ls -l > text.txt

```
اضافه کردن به انتهای یک فایل
<br>
append 
<br>
خروجی دستور رو به انتهای فایل اضافه میکند
- >> 

<br>
#
مدیریت خروجی با اررور یک کامند لاین

-2>&1

```bash
    ls -l | less >> text.txt 2>&1
```

# اضافه کردن دستور و مسیر دلخواه

برای اضافه کردن دستور دلخواه خودمون اول باید یک فایل برای دستور خودمون بسازیم !
برای مثال در مسیر زیر :‌
<br>

```bash
cd ~
vim wellcome
chmod a+x wellcome  # چون که باید برای تمام کاربر ها قابل دسترس باشد 

```
با دستورات بالا فایل ساخته میشه و چون دستوری که میخواییم بسازیم باید برای تمام کاربران باشد دسترسی اجرا رو برای همه کاربران اوکی میکنیم 
<br>

در فایل ساخته شده اطلاعت زیر را میزاریم 
<br>
اطلاعاتی که هنگام فراخوانی دستور ما اجرا میشوند

<br>

wellcome(file created) :

```bash
#!/bin/bash
echo "hello from shello $USER "
```

<br>
سپس به فایل 
.bashrc
در میسر 
home
میریم
و با ویرایشگر بازش میکنیم :‌
<br>

```bash
cd ~
vim .bashrc

```

و در انتهای این فایل متن زیر را میزاریم
<br>
که مسیر مورد نظر را به فایل
 PATH
 اضافه میکند 
 <br>

```bash

PATH=$PATH:/home/user

# user : your linux username directory

```
الان وقت آپدیت کردن هستش

<br>
در ترمینال 

```bash

    source .bashrc

```

الان هم میتونیم دستور خودمون رو در ترمینال وارد کنیم و متنی که در فایلی که ساختیم رو نشون میده 
<br>

```bash

    wellcome

```
