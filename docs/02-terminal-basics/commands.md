# Pipe
به این عملگر پایپ میگویند
<br>
با استفاده از ایشون میتونیم خروجی یک کامند لاین رو به ورودی یک کامند لاین دیگه بدیم

- |

```bash
    cd /
    ls -l | less

```
لیست محتویات رو خط به خط نشون میده

# Redirect 

نتیجه یک کامند را در یک فایل ذخیره میکنه


#
محتویات اون فایل رو پاک میکنه و دوباره مینویستش
Over Write !
- >

```bash

    cd /home/admin

    ls -l > text.txt

```
اضافه کردن به انتهای یک فایل
<br>
append 
<br>
خروجی دستور رو به انتهای فایل اضافه میکند
- >> 

<br>
#
مدیریت خروجی با اررور یک کامند لاین

-2>&1

```bash
    ls -l | less >> text.txt 2>&1
```
