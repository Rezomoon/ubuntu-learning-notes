## nano ##
یک ویرایشگر ساده برای مبتدیان
 ## نصب
 ```bash
 sudo apt install nano
 ```
 ## 👷🏿‍♂️ ##
 حالا بریم ازش استفاده 
 <br>
 اول باید یک فایل متنی بسازیم یا پیدا کنیم که بتونیم یکم خراب کاری کنیم 
 <br>

```bash 
  cd ~ #با این دستور به مسیر روت و اولیه سیستم میریم 
  cd Desktop # به مسیر دسکتاب میریم
  mkdir testFile # ایجاد یک مسیر برای خراب بازی هامون 🙈
  touch text.txt # ایجاد یک فایل تکست 
  nano text.txt
```
    - mkdir : make direction
        - ایجاد یک مسیر جدید 
با این دستورات میتونید یک مسیر و یک فایل تکست درست کنید تا بتونیم با ویرایشگر هامون کار کنیم
    - nano : با درخواست نانو فایل رو توی ویرایشگرش باز میکنه


    خب پایین ااین برنامه یکسری راهنمایی هست فقط همین قدر بهتون بگم که

    M => Alt
    ^ => Ctrl
</br>

بقیه ش با خودتون کار کنید باهاش و یاد بگیرید 
<br>
نکته جدید هم فهمیدید به منم بگید !
🐣🐣



## Vim ##
همون راهنما های نانو رو هم نداره دیگه 
 ## نصب
 ```bash
 sudo apt install vim
 ```
 ## 👷🏿‍♂️ ##
 حالا بریم ازش استفاده 
 <br>
 حب ویم داری پنج مود هستش
 1. Normal Mode 
    - ی سری دستورات کلی مثل حرکت کردن
    - حذف 
    - ذخیره  
 2. Insert Mode
    - میتونید بنویسید و تایپ کنید
 3. Command Mode
    - دستورات ذخیره سرچ 
    - خروج
 4. Visual Mode
    - کپی پیست یا تغییر
 5. Replace Mode
    - جایگیزیینی یک کارکتر با کارکتبر دیگر 
 هر کدوم برای کارایی مشخصی انجام شده است
 <br>


 با زدن
 - i : وارد اینسرت مود میشید 
در اینجا دکمه های کیبوردتون توی ترمینال  نشون داده میشوند
و میتونید به نوشتن بپردازید

- esc
