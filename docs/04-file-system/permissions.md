3.Service User
    برای استفاده از یکسری نرم افزار و دسترسی دادن به کاربران برای استفاده فقط از اون نرم افزار استفاده میشه مثل نرم افزار هایی
    Excel , Mysql , web ,email

## مدیریت مجوز ها 

دو مسیر برای تنظیم یکسری از مجوز ها برای کاربر ها هستش :

۱. User Level : تخصیص مجوز به کاربر
    - مقدار و نوع دسترسی هارو برای یک یزور مشخص میکنیم

۲. Group Level : تخصیصی مجوز به گروه کاربر
    - به جای دادن مجوز تک به تک گروه های مجوز تعریف کنیم
     و کاربران رو در اون گروه ها اضافه کنیم


## اطلاعات کاربر ها در سیستم کجا ذخیره میشوند ؟
این اطلاعات در داخل فایل هایی در مسیر
etc/
ذخیره میشوند 
<br>
1.اطلاعات کاربران :/etc/passwd
با این دستور میتوند بهشون دستسری پیدا کنید :

```bash 

    cd / # با این دستور به مسیر روت میریوید
    cat /etc/passwd # با این دستور فایل مورذ نظر رو در ترمینتال باز میکنید

```
در اول فایل و در سر خط شما یک کاربر به اسم 
root
میبینید و در آخر فایل هم کاربری که باهاش لاگین کردین برای مثال
reza
<br>
یکسری اطلاعات کاربراتون رو میتونید با این فایل به دست بیارید مثلا

```bash
root:x:0:0:root:/root:/bin/bash
```
root : نام کاربر
<br>
x : پسوورد کاربر که به صورت اینکریپت شده نشون میده 
<br>
0 : آیدی کاربر در سیستم
<br>
0 : آیدی گروه کاربر
<br>
root : اطلاعات کاربر مثل نامش و شغلش و...
<br>
/root : آدرس هوم دایرکتوری کاربر
(home directory)

<br>
/bin/bash : آدرس شل هستش که برای اجرای کامند های این کاربر هستش
<br>

<br>

 ## Change Ueser's Group
## عوض کردن گروه یک کاربر 

برای اینکه یک کاربر رو به یک گروه خاص اضافه کنیم :


```bash
    sudo usermod -g groupName userName

```
usermod : یک پکیج که خیلی کار ها میشه باهاش انجام داد
<br>
-g : داریم میگیم که میخواییم روی گروه ها تغییر ایجاد کنیم
    - البته با ایشون ما گروه اصلی کاربر رو ست میکنیم و با 
    -‌G
    میتونید گروه های دیگری هم به کاربر اضافه کنیم

```bash
    sudo usermod -G group1,group2 userName
```
یک نکته مهم این هست که با دستور بالا گروه های یک کاربر دوباره ست میشوند و بعد از این گروه هایی که قبلا بودند ولی در دستور بالا نیومدن دیگر جزو گروه های کاربر نیستند !
its overwrite !
<br>

اگر بخواهیم اتفاق بالا نیوفته از مسیر زیر استفاده میکنیم :
```bash 
 sudp usermod -aG grp1 userName
```

# دسترسی ها
با دستور زیر میتونیم به سه ویژگی فایل ها دسترسی داشته باشیم
صاحب آنها

گروه آنها

دسترسی های آنها
```bash 
    ls -l
```
دسترسی های فایل هارو با یک رشته ده رقمی نشون میده
که حرف اول این رشته اگر با :‌
d : folder (directory)
- : file
c : driver
i : ?


سه کارکتر بعدی در رابطه با مجور صاحب فایل هستش
r : Read

w : write
x : excute
- : No Permissions

سه کارکتر بعدی دسترسی گروه فایل رو توضیح میده
و سه کارکتر آخر دسترسی دیگر افراد رو

# Chang Permissions : 
# عوض کردن دسترسی ها !

```bash
sudo chmod u+x fileName

```

+x( or : w,r) : میگه که چه مجوزی رو به یوزر اضافه کنی

u : Owner User : صاحب فایل
g : Groups
o : Others
a : all

یا اینکه به این صورت عمل کنیم :

```bash

    sudo chmod u=rw- fileName

```



#
برای تغییر و ست کردن دسترسی های یک فایل میتونیم از دستورات زیر استفاده کنیم 

برای عوض کردن فقط 
Owner

```bash
    sudo chown username fileName
```




برای عوض کردن هم 
Owner 
و 
Group

```bash

    sudo chown userName:groupName FileName

```
chown : Change Owner


اگر فقط بخواهیم که گروه یک فایل رو عوض کنیم

```bash
sudo chgrp newGroup FileName
```
-chgrp : Change Group
